# 🌐 Network Security

This section of my Cybersecurity Home Lab focuses on understanding how networks operate, how systems communicate, and how network-based security mechanisms help protect devices and infrastructure.

Through practical experiments using Kali Linux and Windows 11 virtual machines, I explore network security concepts, investigate potential weaknesses, and learn how to implement and evaluate defensive controls.

## 🎯 Objectives

- Understand network communication and fundamental networking concepts.
- Explore network protocols and network-level security mechanisms.
- Learn how firewalls control and filter network traffic.
- Perform network reconnaissance and analyze network activity.
- Understand common network-based attacks and their detection.
- Explore network monitoring and defensive security techniques.
